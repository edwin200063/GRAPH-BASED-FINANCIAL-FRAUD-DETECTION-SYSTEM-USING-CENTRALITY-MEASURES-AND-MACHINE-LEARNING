# Graph-Based Financial Fraud Detection System

An intelligent financial fraud detection system that combines
graph-based centrality measures with machine learning to identify
potential fraudulent transactions.

## 🚀 Features

- Graph-based transaction analysis
- Degree Centrality
- Betweenness Centrality
- Closeness Centrality
- PageRank
- Machine Learning-based fraud classification
- Fraud risk prediction
- Data visualization

## 🛠️ Technologies Used

- Python
- Flask
- Pandas
- NumPy
- NetworkX
- Scikit-learn
- Matplotlib
- Seaborn
